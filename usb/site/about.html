About this setup

This site runs on a small computer sitting behind a home router. The website files live on a USB stick, and a tiny web server reads them straight off it. When someone visits the domain, the router passes the connection through to that machine.

Why bother?

  • The files are yours, on hardware you can physically hold.
  • There is no monthly hosting bill and no account to be suspended.
  • Moving the site to different hardware is a matter of moving the stick.

What it is not

A home connection is not a data centre. Upload speed is limited, the power can go out, and the address can change. That is a fine trade for a personal site, a portfolio, a project page or a family archive — less so for a shop that must never be down.
